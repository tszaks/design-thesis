# Security policy

## Supported versions

Only the latest commit on the default branch is maintained. This repository holds documentation, not running software.

## Reporting a problem

Please report security problems privately, not in a public issue.

Use GitHub private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. If that is not available to you, email tyler@szakacsmedia.com.

## What counts

There is no code to exploit here. These are still worth reporting:

- A code sample in the docs that is unsafe if copied as written (for example, it leaks a secret or disables a security check).
- A link that points to a malicious or hijacked site.
- A secret or personal detail that was committed by mistake.

Wrong advice that is not a security risk is a normal issue. Use the "Report an error" template.
